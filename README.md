# Auditoría de fibroscopios

App web de un solo archivo (HTML, CSS y JavaScript, sin dependencias) para auditar fibroscopios por día y turno.

- Calendario mensual, luego turno 1 (7:00 a 15:00), turno 2 (15:00 a 23:00) y turno 3 (23:00 a 7:00).
- Los fibroscopios se agregan una vez por número de serie y aparecen en todos los turnos.
- Cada uno se marca como Bien, Mal o No aplica. Si está mal, se puede adjuntar una foto de evidencia.
- Los datos se guardan en el navegador de cada dispositivo (localStorage e IndexedDB).

Para usarla, abre `index.html` en el navegador.
